      FAQ

      Is my data uploaded anywhere?

      No. Your browser reads the workbook, creates the files and zips them on your own device. StackMySheets has no server that receives files, so your data never leaves the browser tab.

      How are the files named?

      Each file is named after its tab. Characters that aren't allowed in file names, such as / : * ? " < > |, are replaced with an underscore, and repeated names get “ (2)”, “ (3)” and so on. If you pick only one tab, you get that file directly instead of a .zip.

      Should I choose Excel or CSV?

      Excel files keep each cell's value and number format, so dates stay dates and IDs like 00123 keep their zeros. CSV files contain each value as it's displayed in the workbook, which most other tools can read.

      Are formulas and formatting kept?

      Formulas are replaced by their last calculated values, because a formula that refers to another tab would break once that tab is in a separate file. Number formats are kept in .xlsx files; fonts, colors and other styling are not.

      Can I put files back together?

      Yes. Merge into tabs combines files into one workbook with a tab each, and Stack sheets stacks their rows into one sheet.
