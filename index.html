    FAQ

    Is my data uploaded anywhere?

    No. Your browser reads the files and combines them on your own device. StackMySheets has no server that receives files, so your data never leaves the browser tab.

    Can I combine multiple workbooks with multiple tabs?

    Yes. Drop in as many files as you like, or a whole folder. Every tab of every workbook is listed, grouped by file, and stacked into one sheet. Empty tabs and tabs without a header row start unchecked, and you can uncheck any others.

    What if my columns are in a different order or named slightly differently?

    Columns are matched by the header name in each sheet's first row, not by position, so a different column order is fine.

    Matching ignores capitalization and extra spaces at the start or end of a name, so “Revenue”, “revenue” and “ Revenue ” become one column. Any other difference — say “Qty” vs “Quantity” — counts as a separate column. The Columns panel lists which columns appear in only some sheets, and you choose whether to keep every column (leaving blanks where a sheet doesn't have it) or only the columns every sheet shares. To merge two differently named columns, rename one header in the source file first.

    What file types are supported?

    Excel workbooks (.xlsx and .xls) and CSV files. Other files in a selection or folder are skipped. Each sheet should have its column headers in the first row.

    Can I download as CSV or Excel?

    Both. Download the combined result as an .xlsx workbook with a single sheet, or as a .csv file, and name the file whatever you like. Optional source_file and source_sheet columns record where each row came from.
